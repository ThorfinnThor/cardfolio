# Smart Search V1 technical release gate

Date: 2026-10-01

This gate covers the technical half of D-05. Product states, responsive behavior and accessibility remain the Step-2 Luna gate. A passing technical gate does not authorize merging or deploying.

## Architecture and privacy

- Runtime: static browser-only search over a versioned JSON file. No model, embeddings API, vector database, server route, secret or paid provider is used.
- Identity: every result remains a TCGdex card ID and is hydrated through the existing catalog path. Image bytes are neither copied nor stored.
- Query privacy: artwork queries stay in the browser. Cardfolio does not log or transmit them.
- Replaceability: UI consumers depend on `SmartSearchAdapter`, `SmartSearchQuery` and `SmartSearchHit`; V1 provides `LocalStaticSmartSearchAdapter` only.
- Feature gate: `NEXT_PUBLIC_FEATURE_SMART_SEARCH=false` removes the productive entry point. The default is enabled for the prepared review build.
- Failure boundary: index loading supports a caller abort signal and an explicit 8-second timeout. The ordinary name/number catalog path is independent.

## Reviewed source and deterministic build

- Source manifest: `data/semantic/card-artwork-tags-v1.manifest.json`
- Reviewed source rows: `data/semantic/card-artwork-tags-v1.jsonl`
- Public index: `public/data/semantic/card-artwork-search-v1.json`
- Index version: 1
- Frozen vocabulary: 23 visual tags
- Build: `npm run semantic:index:build`
- Reproducibility check: `npm run semantic:index:check`
- Fixed evaluation: `npm run semantic:evaluate`

The public index is generated only from the committed reviewed rows. The scheduled catalog workflow audits coverage but never invents or publishes tags for new cards.

## Coverage and payload

- Reviewed/indexed cards: 19,635
- Physical English source cards with image references: 19,669
- Untagged eligible backlog: 0
- Explicitly blocked: 34 cards in `dc1`; TCGdex advertises image references but the checked source variants return HTTP 404.
- Pokémon TCG Pocket: excluded from the physical catalog before this audit.
- Raw public payload: 2,266,481 bytes
- Gzip level-9 payload: 419,340 bytes

`data/semantic/catalog-coverage.json` is regenerated by the weekly public-data job. A new physical card with an image reference appears as an explicit backlog ID in the workflow summary and committed coverage report; it is not silently treated as reviewed.

## Quality benchmark

- Historical manually reviewed prototype: 227 relevant results out of 240 top-eight positions over 30 queries (94.6%).
- Automated fixed suite: 50 predeclared motif queries, 400 possible top-eight positions.
- Current semantic result: 394/400 relevant positions.
- Identity-only lexical baseline: 40/400 relevant positions.
- Automated release floors: no per-query shortfall, at least 375/400 semantic relevance and more than 300 relevant positions above the lexical baseline.

The evaluation fixture is committed before runtime and scores only declared tag/caption evidence. It is a regression guard, not a claim that generated tags are objectively correct for every artwork.

## Cost, latency and ongoing operation

- Runtime provider cost: none.
- Scheduled inference cost: none; GitHub Actions only compares catalog identities with the reviewed source.
- Initial load cost: one lazily requested 419,340-byte gzip payload under the current build.
- Search computation: synchronous local scoring after the index has loaded; the 50-query Vitest evaluation completes in approximately one second on the development machine, including fixture/index parsing and test overhead.
- New cards: require a separate human-reviewed tagging pass followed by the deterministic build command.

Exact browser load/search timings and Core Web Vitals must be recorded during Step 2 at 375, 768, 1024 and 1440 px. They are deliberately not inferred from a Node test.

## Decision

Technical gate: **pass for Step-2 product integration**.

Public-release gate: **not yet passed**. Luna must still verify feature-off behavior in the rendered product, timeout/malformed/no-result recovery, the normal-search CTA, language selection, keyboard/focus/screenreader behavior and the four required viewports. Merge and deployment remain user-authorized actions.
